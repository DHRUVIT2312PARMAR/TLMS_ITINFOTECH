🔧 SETUP OPTIONS:

Choose one of the following:

OPTION 1: Local MongoDB (Recommended for Development)
═══════════════════════════════════════════════════════════════

Step 1: Install MongoDB Community Edition
  Windows:  Download from https://www.mongodb.com/try/download/community
  macOS:    brew install mongodb-community
  Linux:    sudo apt-get install -y mongodb

Step 2: Start MongoDB
  Windows:  mongod
  macOS:    brew services start mongodb-community
  Linux:    sudo systemctl start mongod

Step 3: Verify Connection
  mongosh
  (should open MongoDB shell without errors)

Step 4: Update server/.env
  MONGODB_URI=mongodb://localhost:27017/tlms_itinfotech

Step 5: Seed Database
  npm run seed (in server directory)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

OPTION 2: MongoDB Atlas (Cloud Database - Recommended for Production)
═════════════════════════════════════════════════════════════════════

Step 1: Create MongoDB Atlas Account
  Visit: https://www.mongodb.com/cloud/atlas
  Click "Sign Up"
  Enter your details
  Verify email

Step 2: Create Cluster
  Click "Create Cluster"
  Choose Free Tier (M0)
  Select your region (Asia-South recommended for India)
  Click "Create"
  Wait 5-10 minutes for cluster to deploy

Step 3: Create Database User
  Go to "Security" → "Database Access"
  Click "Add New Database User"
  Username: tlms_user
  Password: Create a strong password
  Click "Add User"

Step 4: Get Connection String
  Go to "Clusters" → "Connect"
  Choose "Connect your application"
  Copy connection string
  It looks like: mongodb+srv://user:password@cluster.mongodb.net/dbname

Step 5: Setup IP Whitelist
  Go to "Security" → "Network Access"
  Click "Add IP Address"
  Click "Allow Access from Anywhere" (for development)
  Click "Confirm"

Step 6: Update server/.env
  MONGODB_URI=mongodb+srv://tlms_user:YOUR_PASSWORD@cluster.mongodb.net/tlms_itinfotech

  Replace:
  • YOUR_PASSWORD with your database user password
  • cluster with your cluster name

Step 7: Seed Database
  npm run seed (in server directory)

❌ TROUBLESHOOTING:

Problem: "MongoDB connection failed"
Solution:
  • Make sure MongoDB is running: mongod
  • Check MONGODB_URI in .env
  • Verify localhost:27017 is accessible

Problem: "ECONNREFUSED 127.0.0.1:27017"
Solution:
  • MongoDB not running
  • Run: mongod (local) or check MongoDB Atlas status (cloud)

Problem: "E11000 duplicate key error"
Solution:
  • Run: npm run seed
  • This clears old data and reseeds

Problem: Authentication endpoint still returns placeholder
Solution:
  • Clear node_modules cache
  • Restart server: npm run server
  • Check if authController is imported correctly

Problem: Can't connect to MongoDB Atlas
Solution:
  • Verify username and password are correct
  • Check IP whitelist (add your current IP)
  • Ensure database name is correct in connection string
