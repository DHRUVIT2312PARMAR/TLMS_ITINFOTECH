ERROR: "Permission denied" / "403 Unauthorized"

CAUSE: GitHub authentication issue with HTTPS

SOLUTION OPTIONS:
═════════════════════════════════════════════════════════════════════════

OPTION 1: Use Personal Access Token (Recommended)
═════════════════════════════════════════════════════════════════════════

Step 1: Generate GitHub Personal Access Token
  1. Go to: https://github.com/settings/tokens
  2. Click "Generate new token"
  3. Give it a name: "TLMS_ITINFOTECH"
  4. Select scopes:
     ☑ repo (Full control of private repositories)
     ☑ write:packages
     ☑ read:packages
  5. Click "Generate token"
  6. Copy the token (save it somewhere safe!)

Step 2: Update Git Remote with Token
  Replace YOUR_TOKEN with the token you just created:

  git remote set-url origin https://YOUR_TOKEN@github.com/DHRUVIT2312PARMAR/TLMS_ITINFOTECH.git

  Example:
  git remote set-url origin https://ghp_abc123xyz456@github.com/DHRUVIT2312PARMAR/TLMS_ITINFOTECH.git

Step 3: Push to GitHub
  git push -u origin main

  You should see:
  ✅ Enumerating objects: ...
  ✅ Writing objects: ...
  ✅ Counting objects: ...
  ✅ Branch 'main' set up to track remote branch 'main' from 'origin'

OPTION 2: Use SSH (Alternative)
═════════════════════════════════════════════════════════════════════════

Step 1: Generate SSH Key (if you don't have one)
  ssh-keygen -t ed25519 -C "dhruvit@itinfotech.in"
  
  Press Enter for all prompts
  
  Key saved at: ~/.ssh/id_ed25519

Step 2: Add SSH Key to GitHub
  1. Go to: https://github.com/settings/keys
  2. Click "New SSH key"
  3. Title: "TLMS_ITINFOTECH"
  4. Paste your public key:
     cat ~/.ssh/id_ed25519.pub (on Mac/Linux)
     type $profile\..\.ssh\id_ed25519.pub (on Windows PowerShell)
  5. Click "Add SSH key"

Step 3: Update Git Remote to SSH
  git remote set-url origin git@github.com:DHRUVIT2312PARMAR/TLMS_ITINFOTECH.git

Step 4: Push to GitHub
  git push -u origin main
